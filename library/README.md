# Library

Full texts of public-domain books, kept as style references for the voices of any book in this repo (see each book's `voices/00-author-library.md`). Shared by all books; nothing book-specific goes here.

All texts are public-domain English translations, taken from Standard Ebooks (CC0, based on Project Gutenberg transcriptions) and converted to plain text. Modern translations (e.g. Pevear and Volokhonsky) are under copyright and are not included.
