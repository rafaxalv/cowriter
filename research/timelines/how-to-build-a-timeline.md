# How to build a timeline (instructions)

Oct 2, 2026 · Rafael

Every timeline in this folder follows the same recipe, so they can be read side by side and kept in sync with the research docs. The worked example is [Timeline — Paraguayan War (1811–1892)](paraguayan-war-1811-1892.md) ([Drive original](https://docs.google.com/document/d/1gKmUZvZErMlRzLK2mcBy1nryfZ8-tHoN-K8CnXVePbU/edit)): copy its structure for any new timeline.

## 1. What a timeline is for

  - It turns the research into **dated facts the book can stand on**, sorted by how much we can trust them.
  - It shows **where the invented characters meet real history**, so plot dates never contradict the record.
  - It is a **living document**: it is updated whenever a research doc, the Character Bible or the Book Concept changes.

## 2. Naming and location

  - File name: **Timeline — &lt;Topic&gt; (&lt;start&gt;–&lt;end&gt;)**, e.g. "Timeline — Paraguayan War (1811–1892)".
  - Every timeline lives in this **Timelines** folder, one copy only (no duplicates elsewhere in Drive).
  - Written in English, like the other working docs. Keep Portuguese, Spanish or Guaraní terms as they are, in italics where useful (*carta de alforria*, *residentas*).

## 3. How to gather the material

1.  **Read every doc in the book's Drive folder** that touches the topic: research notes, Dados gerais, Character Bible, Book Concept, Região, and any new doc. Pull every dated fact.
2.  **Start well before the main event.** Go back far enough to show the causes and context (the Paraguayan War timeline starts in 1811 for a war that began in 1864), and run past the end to show the consequences (it runs to 1892).
3.  **Check dates against sources you actually open** (Wikipedia, legislation sites, academic articles). A search-result snippet is not a source.
4.  **When sources disagree**, keep both versions in the row, mark it *Contested*, and add the conflict to the open questions.
5.  **Keep folklore and rumour on purpose.** Low-reliability material is useful as things a character says. Tag it *Tradition* rather than deleting it.

## 4. Document structure (in this order)

1.  **Title and byline** (date and author).
2.  **Lead paragraph**: the answer in two or three sentences (when it happened, why it matters for the book).
3.  **How to use and update this timeline**: the reliability scale, links to every source doc, and how to add rows. Copy this section from the example and adjust the links.
4.  **At a glance**: a short table of the main phases (Phase, Dates, Turning points). This gives the shape before the detail.
5.  **One section per period**, each with:
      - a heading with the years ("1866–1868: invasion, Curupayty and the siege of Humaitá");
      - a one- or two-sentence lead saying what changed in that period;
      - a table with exactly four columns: **Date | Event | Reliability | Source**.
6.  **Story hooks**: a table linking the periods to the characters: **Period | The man (Character Bible) | Real event he is placed in | Other characters | Open question**. Adapt the second column to whoever the timeline is about (e.g. "The woman from Spain").
7.  **Sources and open questions**: the web pages opened, then a checklist of what still needs checking.

## 5. Rules for the tables

  - **One row per event**, in date order inside each period.
  - **Date column**: "12 Nov 1864" for exact days, "Nov 1865" or "1867" when that is all we know, "Dec 1864–Jan 1865" for spans. Never invent a precision the sources don't give.
  - **Event column**: one or two short sentences. Name the people and places. Add the detail that makes it useful for the book (a zuavo who died there, a character link) in the same cell.
  - **Reliability column**, one word from this scale (the same as the research notes):

| **Tag** | **Meaning** | **How to use it in the book** |
| :-: | :-: | :-: |
| Documented | Backed by archives, official records or serious scholarship | Can be narrated as fact |
| Contested | Historians or sources disagree | Show it through characters who disagree, or stay vague |
| Tradition | Oral, folk, propaganda or family tradition; not verified | Put it in a character's mouth |
| To verify | Taken from general knowledge, not yet checked against a source | Check before relying on it |

  - **Source column**: the short name of the project doc the fact came from (Research Notes, Pesquisa completa, Dados gerais, Character Bible, Book Concept, Região), or "Web (&lt;site&gt;)" for an opened web page. This tells you which rows to revisit when a doc changes.

## 6. Writing style

  - Short, plain sentences (under 25 words). Specific names, dates and numbers rather than adjectives.
  - No lectures: each row says what happened, not what it means. Interpretation goes in the period's lead sentence or in the story hooks.
  - Numbers that historians argue about (death tolls, troop counts) are given as a range, with the disagreement noted.

## 7. Keeping timelines up to date

  - **When a research doc changes:** search the timeline's Source column for that doc's name and check those rows.
  - **When a fact is checked:** change "To verify" to the right tag and add the web page to Sources.
  - **When the Character Bible changes:** update the Story hooks table so ages and dates still fit.
  - **To ask Claude for an update:** "Update the timeline from the latest docs in the book folder, following the instructions in the Timelines folder."
  - Tick off the open questions as they are answered rather than deleting them, so the reasoning stays visible.
